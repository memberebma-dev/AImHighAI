Security

Last updated November 21, 2026

How we protect data

  • HTTPS everywhere, with strict transport security.
  • Database row-level security so each account only sees its own records.
  • Secret keys stored only in our hosting provider's encrypted environment settings, never in code.
  • Payments handled entirely by Stripe (PCI DSS Level 1).
  • Security headers that block clickjacking and content sniffing.

Report a vulnerability

Email memberebma@gmail.com with "Security report" in the subject, including steps to reproduce. We'll reply within 3 business days. Please give us reasonable time to fix the issue before telling others, don't access or change other people's data, and don't run tests that could disrupt the service. Good-faith research under these rules is welcome and we won't pursue legal action over it.
